#### The Narrative & Challenge
You are hired as Lead UX Engineers for a rising SDG-focused e-commerce marketplace. The previous development team prioritized raw short-term conversion metrics by embedding heavy psychological coercions ("dark patterns") into the checkout form. 

**The Mission:** 
1. **Audit the Checkout:** Identify, document, and label the **six distinct dark patterns** hidden within the starter code.
2. **Deconstruct the Code:** Trace how the HTML elements, CSS specificity rules, and form attributes are styled to manipulate the user's focus, scale, reading patterns, and color psychology.
3. **Execute the Clean Redesign:** Refactor the codebase into a transparent, accessible checkout interface. Achieve clean visual hierarchy, proper typographic lines, high-contrast states, and standard opt-in structures.

#### Group Setup
* **Time:** 30-minute workshop sprint.
* **Deliverable:** A single folder `/ux-audit/` in your repository containing `coercive-checkout.html` (the annotated audit), `ethical-checkout.html` (the code solution).
